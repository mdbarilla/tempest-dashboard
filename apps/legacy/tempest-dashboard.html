Setup Required

  1. Go to tempestwx.com and sign in
  2. Navigate to Settings → Data Authorizations → Create Token
  3. Copy your token
  4. Open this file in a text editor (like TextEdit or Notepad)
  5. Find line 374 and replace YOUR_API_TOKEN_HERE with your token
  6. Find line 375 and replace YOUR_STATION_ID_HERE with your station ID
  7. Save the file and reload this page

Need your Station ID? Visit: https://swd.weatherflow.com/swd/rest/stations?token=YOUR_TOKEN in your browser and look for the "station_id" number.
